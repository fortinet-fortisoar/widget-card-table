# Card Table

## Release Information

- **Version**: 1.0.0

- **Certified**: Yes

- **Publisher**: Fortinet

- **Compatibility**: FortiSOAR 8.0.0 and later

- **Applicable**: Modules' List View

## Overview

The **Card Table** widget displays a grouped summary of records from any FortiSOAR module directly on a module's list view. Each row in the table represents a group, identified by a field you choose, with the count of matching records shown alongside it — giving you an at-a-glance breakdown without leaving the listing page.

The widget supports flexible filtering through single conditions and grouped condition sets, making it easy to scope the summary to only the records that matter.

### Key Features

- Group records from any module by any field and display counts per group
- Filter records using single conditions or nested condition sets
- Control the number of records fetched using a configurable limit
- Scope results by record assignment to focus on relevant subsets
- Refresh or search the summary directly from the widget header
